# Debt Sweeper

**Debt Sweeper** is a neon arcade shooter with a finance twist — defend your Net Worth Core from compounding debt.

## Play

**[Play in your browser](https://coderscamp-nation.github.io/DebtSweeper/)**

No install — works on desktop and mobile.

## Controls

- **Move** — WASD / arrow keys (touch: drag)
- **Fire** — auto-aim beams at nearby debt
- **Overpay** — `Space` or tap to burst-clear pressure

Pick **Easy / Medium / Hard**, survive waves, beat bosses, and climb the local hall of solvency.

## Run locally

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```
